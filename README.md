# 조삼모사 (朝三暮四)

원숭이들에게 아침에 셋, 저녁에 넷을 나눠 주는 도트 인크리멘탈 게임입니다.
하루에 주는 양은 처음부터 끝까지 7입니다. 포장만 바뀝니다.

**바로 플레이:** https://baramutzero-netizen.github.io/josammosa/

`index.html` 한 파일로 돌아가서, 내려받아 브라우저로 열어도 됩니다(그림·소리·글꼴이 모두 한 파일에 들어 있음).

## 하는 법

- 처음에 **도토리 버전**(도토리 7개)과 **쌀 버전**(쌀 7톨) 중 하나를 고릅니다. 설정에서 언제든 바꿀 수 있고 진행은 그대로입니다.
- 현장 탭에서 버튼(또는 장면, 스페이스바)을 눌러 그릇에 하나씩 던집니다. 일곱 개가 차면 하루가 끝나고 원숭이들이 환호합니다.
- 처음엔 아침 셋 저녁 넷이라 원숭이들이 화를 냅니다. **조사모삼**을 사면 아침 넷 저녁 셋으로 바뀌고 다들 기뻐합니다.
- 경영도 탭의 노드 트리에서 환호로 전략을 삽니다. 아직 가지 않은 장소의 노드는 `?`로 가려집니다.
- 모든 전략을 갖춘 뒤 **우주 결산**을 사면 엔딩이 나옵니다. 한 판은 6분 남짓입니다.

## 담긴 것

- **장소 7곳:** 산골 → 장터 → 백화점 → 홈쇼핑 → 증권가 → 중앙은행 → 우주
- **전략 72개:** 1+1 행사, 정가 14개 오늘만 7개, 명품 포장, 무이자 7개월 할부, 마감 임박 자막, 정기구독, 액면분할, 레버리지 3배, 코인, 양적완화, 헬리콥터 살포, 화성 선물, 메타버스 농장…
- **원숭이:** 쌀 버전의 쌀숭이(쌀포대)와 도토리 버전의 도숭이(도토리 자루), 일본원숭이, 고릴라, 오랑우탄, 황금들창코원숭이, 우주비행사 원숭이, 서유기의 제천대성(72마리 분신)까지
- **악단:** 장소마다 두 파트. 7/8박자로 연주하며, 조사모삼을 사면 강세가 3+4에서 4+3으로 바뀝니다(대나무·손뼉, 꽹과리·장구, 엘리베이터 음악·보사노바, 방송 브라스, 트레이딩 비트·전화벨, 팀파니·조폐기, 신스 아르페지오·무중력 베이스)
- **엔딩:** 감사 원숭이의 계산기, 그리고 거울
- **결산 그림:** 끝나면 결과 카드 PNG를 저장하거나 공유할 수 있습니다

## 폴더

| 경로 | 내용 |
| --- | --- |
| `index.html` | 완성된 게임 한 파일 |
| `game.src.html` | 게임 소스 (글꼴·그림 자리 표시자 포함) |
| `assets/aseprite/` | 도트 원본 `.aseprite` (`monkey.aseprite`는 원숭이 품종별 프레임, happy/angry 태그) |
| `assets/png/` | 같은 그림 4배 PNG |
| `tools/sprites.py` | 모든 도트의 원본 데이터 → `sprites.json`, `.aseprite`, PNG 생성 |
| `tools/build.py` | 글꼴을 쓰는 글자만 잘라 넣고 `index.html`을 만듦 |

## 다시 빌드하기

Python 3와 갈무리 글꼴(`npm pack galmuri`)이 필요합니다.

```bash
pip install pillow fonttools brotli
cd tools && python3 sprites.py && cd ..
GALMURI=경로/package/dist python3 tools/build.py
```
